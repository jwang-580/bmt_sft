# Registry question metadata

`CIBMTR_Form_2400_R11_Items_simplified.csv` contains the study's 129 retained questions from CIBMTR Form 2400, revision 11. It contains no patient rows, clinical notes, or patient answers. Original field numbers, categories, wording, and stored options are preserved; the catalog is not renumbered.

This is third-party form content. Source notices in the stored form text identify the Medical College of Wisconsin and NMDP as rights holders. No new license to that content is granted by this repository. The catalog preserves the actual prompt input, including source formatting artifacts; cleaning or changing it requires a new catalog version for reproducible comparisons.
